7.2 (extra) Text Readout Score
  1. Make UI/Text - call it -Score Counter-
  2. Add Component/Script
  3. Create Text -uiText- and -score- variables
pseudo-code
private Text uiText;
private long score = 0;
  1. In Start - uiText = GetComponent<Text>();
pseudo-code
void Start () {
uiText = this.GetComponent<Text>();
updateScoreCounter();
}
  1. Add Points (run script when key is pressed - remember how to do this?)
    1. public void addPoints(int points){
    2. score += points;
    3. updateScoreCounter();
    4. }
    5. Method outside of update:
pseudo-code
private void updateScoreCounter(){
uiText.text = "<color=blue>Score</color>: " + score;
}
