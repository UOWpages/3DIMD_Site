Layout / Main editors

  • 3D Viewport: Primary workspace for modeling (navigation, select, transform, sculpting preview). Most modeling actions happen here.
  • Outliner: Scene hierarchy � shows objects and collections; use it to hide/lock/select objects and organize your scene.
  • Properties Editor: Contextual panels (Editor Type) for Object, Modifier, Mesh Data, Material, Object Constraints, Render settings, etc. Modifiers (Mirror, Subsurf, Boolean, Bevel) live here.
  • Sidebar (N): View / Tool / Item panels with transform values, tool options, and viewport display toggles.
  • Toolbar (left of 3D View): Quick access to tools (Move, Rotate, Scale, Transform, Extrude, Knife, Loop Cut). Can be hidden (T).
  • Top Info Bar / Header: Contains Add menu, current mode, snapping, pivot, overlays, shading, and global settings.
  • Workspaces � I tend to work in Layout with Xray and all coordinate views, and switch to Modelling for shaded and final view.
  • UV/Image Editor, Shader Editor, and other editors are available when working on UVs/materials � often used after base modeling.

Windows

  • Go to top corner of a window to get a �+� sign
  • This can be dragged down to form a new window.
  • Dragging this across an existing window give the option to split it.
  • It can also be dragged into an existing window to join them.

Modes and selection

  • Object Mode: Move/scale/rotate whole objects, add modifiers, manage collections.
  • Edit Mode: Polygon/edge/vertex-level modeling. Toggle with Tab.
  • Selection types: Vertex/Edge/Face (1 / 2 / 3 keys or icons). Use Alt+Click to select an edge loop, Ctrl+Alt+Click to select ring loops (keymap dependent).
  • Lasso/Box/Circle select: Ctrl/Cmd + drag tools or B (box), C (circle), Lasso from the tool shelf.

Transforms & navigation

  • Navigation: Middle mouse drag to orbit, Shift+MMB to pan, scroll to zoom (or Numpad keys for orthographic views).
  • Move/Rotate/Scale: G / R / S. Constrain axes with X / Y / Z (e.g., G ? Z). Type numerical values after the shortcut.
  • Precision: Hold Shift for fine control. Use axis constraints and orientation (Global, Local, Normal, View).
  • Apply transforms: Object Mode ? Ctrl+A ? Apply Location/Rotation/Scale (important before some modeling ops).

Common Edit Mode tools & operations

  • Extrude: E (faces/verts/edges)
  • Inset faces: I
  • Bevel: Ctrl+B (edges), use mouse wheel to add segments
  • Loop cut: Ctrl+R (LMB click to place, right-click to center)
  • Merge vertices: M (or Alt+M in some keymaps)
  • Fill / Make face: F
  • Delete: X (choose vertices/edges/faces)
  • Separate: P ? Selection (make new object)
  • Knife: K for manual cuts
  • Rip / Rip fill: V (depending on keymap)
  • Edge slide / vertex slide: G then G (or use dedicated tools)
  • Snap: Shift+Tab toggles snapping (Vertex, Edge, Face, Increment). Use Ctrl while transforming for temporary snap.
  • Proportional Editing: O to toggle; mouse wheel changes falloff radius for soft transforms.

Modifiers & non-destructive workflow

  • Mirror: Symmetry across axis; enable Clipping to merge at center.
  • Subdivision Surface: Smooths geometry (add as modifier; use supporting loops to keep edges sharp).
  • Boolean: For cutting/combining complex shapes (prefer robust workflows: signed booleans, clean topology after operation).
  • Bevel, Solidify, Array: Common modeling helpers.
  • Order matters: modifier stack is applied top?bottom; move modifiers to get desired results.
  • Use separate objects (P) or collections for components you want to edit independently.

Viewport display & shading

  • Shading modes: Wireframe (Z?Wireframe), Solid, Material Preview, Rendered.
  • Overlays: Toggle visibility of gizmos, face orientation, normals, origins, grid, etc.
  • Shade Smooth / Shade Flat: Right-click ? Shade Smooth for a smoothed normal look; add supporting loops for sharpness.
  • X-Ray / X-Ray toggle: Makes selecting through geometry easier (Z menu or X-Ray slider).
  • Show Gizmo, Show Overlays, Toggle Xray and ViewPort Shading is ideal for modeling
  • Z plus wheel menu for Wireframe, Solid toggling

Outliner & scene organization

  • Collections: Group objects for visibility, selection, rendering control.
  • Lock selectability / visibility / renderability per object or collection to avoid accidental edits.

Useful shortcuts (quick reference)

  • Tab: Toggle Object/Edit Mode
  • Shift-A: Add Object Primitives
  • G / R / S: Move / Rotate / Scale
  • Ctrl+R: Loop Cut
  • Ctrl+B: Bevel
  • E: Extrude
  • I: Inset
  • F: Fill face
  • X (or Delete): Remove elements
  • Shift+D: Duplicate (right-click to keep in place)
  • M: Move to Collection (or Merge depending on keymap)
  • O: Toggle Proportional Editing
  • Shift+Tab: Toggle Snapping
  • Ctrl+A: Apply transforms
  • 1/2/3: Vertex/Edge/Face select

Modeling tips & best practices

  • Move in one axis at a time
  • Check whether in Object or Edit mode when adding objects.
  • Work non-destructively: use modifiers before applying them so you can iterate.
  • Apply transforms (Ctrl+A) before using modifiers, boolean ops, or bevels to avoid skewed results.
  • Keep quad-based topology where possible; avoid n-gons in deforming areas.
  • Use supporting edge loops to control sharpness when using Subdivision Surface.
  • Clean up after booleans: merge vertices, remove doubles (Merge by Distance), and retopologize if needed.
  • Organize into collections and name objects clearly.
  • Save versions frequently and use incremental saves (file_v01.blend, etc.).

Customizing & productivity

  • Pie menus (add-on) and custom keymaps can speed modeling.
  • Tool settings in the toolbar and the topbar let you fine-tune tools without memorizing all shortcuts.
  • Learn context menus (right-click) � they expose commonly used operations quickly.
  • Enable addons like LoopTools, F2, and Mesh: Extra Tools for faster workflows.
