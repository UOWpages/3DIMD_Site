  1. Import Lego Brick and add narrative animation
    1. Create Plane, place at 0,0,0, and scale to 10,1,5
    2. Import a single lego brick and duplicate it twice, rename to brick 01, 02, 03
    3. Duplicate and replace materials to be R,G,B
    4. Position with snapping (hold CTRL) https://learn.unity.com/tutorial/unity-tips#5c7f8528edbc2a002053b473
    5. Select Brick we will animate in X
    6. Open Window, Animation
    7. Create Animator/Animation, name as AnimX.anim
    8. Add Property: Transform/Position
    9. Turn on record button
    10. See the start key
    11. Drag transport to 0:30,
    12. With Translate gimbal selected ("w" key), drag brick in X axis, See the new key made by recording. Turn off recording mode
    13. Start keyframe of position.x at 0:00 - copy
    14. Drag transport to 1:00, paste position.x key here
    15. Drag transport bar back and forth to check animation.
    16. Open Assets Folder and Inspector to see Animator Controller
    17. Open Animator Window to see State machine and Animation
    18. Press play button to view narrative animation created in Unity!
    19. Repeat for other bricks in Y and Z axes, try without recording.
  2. Program input key to trigger Unity Animations
    1. Create New Script for Lego Brick 01 - call Animator Trigger
    2. With Lego Brick 01 selected:
    3. Create New Animation in Animation Window - name Rest
    4. This should be at the start position and not move
    5. Drag the Rest animation into the Animator window for Lego Brick 01
    6. Right click "Rest" Animation to make it the default state (There needs to be one at all times)
    7. Delete transition to AnimX, connect to Any State
    8. Make transition to Exit State
    9. Use key input code to trigger and play AnimX
    10. Add a Box collider and select trigger box
    11. Use mousedown code to trigger and play AnimX
    12. Repeat for other bricks

Pseudo Code: Task 4.1 - Trigger Animations in Animator: AnimatorTrigger

using System.Collections;

using System.Collections.Generic;

using UnityEngine;

public class AnimatorTrigger : MonoBehaviour

{

// Start is called before the first frame update

void Start()

{

}

// Update is called once per frame

void Update()

{

if (Input.GetKeyDown("1"))

{

this.GetComponent<Animator>().Play("AnimX");

}

}

void OnMouseDown()

{

this.GetComponent<Animator>().Play("AnimX");

}

}

  1. Import brick with multiple animations - array
  2. Divide into resting, explode, explode rest, and implode animations
    1. Rest - 0,0
    2. Explode - 0-20
    3. Explode Rest -20-21 (needed to work correctly)
    4. Implode = 21-40
  3. Setup animator controller and explode, implode off of entry
  4. Create bricks to trigger explode and implode
  5. Put script on explode brick to access the explode by public GO variable
  6. Put script on implode brick to access the implode by FindObject.GetComponent.Script
  7. This relies on Animator States to control the exploded, imploded states

Alternate scripted version: Have Boolean to check for exploded, imploded state , Trigger by Mouse Click on Array (all is internal on brick array script)

Make sure you use an explode animation of 20-21 (1 frame) for this to work properly

BrickTriggerExplode

using System.Collections;

using System.Collections.Generic;

using UnityEngine;

public class BrickTriggerExplode : MonoBehaviour

{

public GameObject brickArray;

// Use this for initialization

void Start()

{

}

// Update is called once per frame

void Update()

{

}

public void OnMouseDown()

{

brickArray.GetComponent<Animator>().Play("Explode");

}

}
