  2. Or To convert existing Built-In(Standard) 3D project to URP:
    1. https://youtu.be/KpTK-OraZ-g
    2. In Existing project, Import Universal RP package from Unity Registry in Package Manager
    3. Right Click in Project window ï¿½ Greate Rendering/URP Asset with Universal Renderer
    4. Edit/Project Settings/Graphics/Select the URP (Universal Render Pipeline Asset you created above
    5. Convert materials: Window/Rendering/Render Pipeline Converter/
      1. Select Built in to URP

      3. Tick Material Upgrade

      5. Click Convert assets

    6. Trouble shoot individual materials with change from Standard to URP in Inspector

  3. Create new Scene: Standard URP (Has Global Volume)

    https://gyazo.com/16081b90e34d96d6a0cabf2d55c1e533

  4. Import Café model ï¿½ extract Textures and Materials to created folders
  5. Drag Café model into new scene
  6. Open and Check Lighting tab (Top Menu/Window/Rendering/Lighting) - Create New Lighting Setting from Button ï¿½Newï¿½ at the top of the lighting window
  7. Enable Baked Global Illumination under Mixed Lighting, and baked Indirect in the Lighting Mode drop down box
  8. Enable Auto Generate at bottom of page ï¿½ this eliminates the black shadows by using ambient light from the skybox

    https://gyazo.com/cddb73d6d436fbd4b4333432d55587ea

  9. Go to Edit/Project Settings/Player/Other Settings ï¿½ change color space to Linear
  10. In Edit/Project Settings/Quality/Rendering/RenderPipelineAsset - check - should be URP-HighFidelity (Universal Render Pipeline Asset)
  11. In the Inspector/Directional Light ï¿½ rotate to 30,-150,0 or to taste
  12. In Lighting Window ï¿½ Environment Tab, test effects of using color rather than Skybox
  13. Baking Indirect Light:
    1. Lighting/Scene ï¿½ Untick Auto-Generate at bottom
    2. Lighting mode: Dropdown box to to Baked Indirect
    3. Lightmapper: Dropdown box to Progressive GPU
    4. Lightmap Compression: Dropdown box to None
    5. In Hierarchy, Inspector, make Café Static (and children)
    6. In Hierarchy, Inspector, Directional Light ï¿½
      1. Mode: Dropdown box to Mixed
      2. Shadows/Realtime Shadows/Bias: dropdown box to Custom, zero out
    7. In Lighting Window ï¿½ clear baked data (recalculate Environment), then ï¿½Generate Lightingï¿½
    8. This is Baked indirect lighting with real time shadows.
  14. Add Fog
    1. Lighting Window/Environment/ Tick Fog
    2. Select Linear in Mode drop down box
    3. Set start to 5, end to 150
    4. Pick color
  15. Post Processing Setup - Camera
    1. No Post Processing layers or setup needed with URP
  16. Post Processing Setup ï¿½ Global Volume
    1. No Post Processing Volume setup needed with URP
      1. Just make sure Global Volume in Hierarchy is active and its component Volume/Mode is Global
      2. Can adjust Weight of overall effect
      3. Check it has profile
      4. If you donï¿½t have a Global Volume, add it from top Menu/Game Object/Volume/Global Volume
      5. Create new Volume Profile in Inspectore window for Global Volume

        https://gyazo.com/75a4c1851dfc5814e20ab17184c3114a

    2. Just Add Overrides for Options
      1. Defaults are Tonemapping, Bloom
      2. Tick to activate needed settings and adjust
      3. Suggested Overrides:
        1. Ambient Occlusion
        2. Depth of Field
        3. Motion Blur
        4. Vignette
    3. For Glow/Emission ï¿½
      1. Check HDR in Main Camera (may be in First Person Character) is set to ï¿½Use Settings from Render Pipeline Assetï¿½
        1. Create a Dark Skybox
          1. Create Material
          2. In shader dropdown select Skybox/Procedural
          3. Adjust down Sun Tint, Atmosphere Tint
          4. Take HDR exposure down to .3
          5. Drag into Lighting/Environment/SkyboxMaterial box to replace old Skybox Material
          6. Adjust Directional light Color down in Hierarchy to taste
          7. Select Café Railings and adjust material to less than 100% White
        2. Add Bloom to Volume
          1. Try adjustments above 1 for intensity, and about .8 for threshold
          2. You will have to adjust the Skybox and some materials to not be pure white, so they do not bloom
          3. You can now add objects with Emission materials for glow.
        3. Glow - Create Cube with Emission Material
          1. Create Material
          2. Tick Emission
          3. Below Emmission select Color Picker box nest to Emmission map tickbox, Pick HDR color to be bright
          4. In same color picker select intensity to be 1 or above

            https://gyazo.com/130512b57e52f937ed39a92fa3e49f2f

        4. At this point you will want to rethink your Directional Light(s) and Rebake!
        5. Try it with the actual Light objects....
      2. References for Bloom

Troubleshooting (Settings to check):

  1. Top Menu/Edit/Project Settings/Quality/Current Active Quality Level = High Fidelity
  2. Top Menu/Edit/Project Settings/Quality/Rendering/Render Pipeline Asset = URP ï¿½HighFidelity(Universal Render Pipeline Asset)
  3. Window/Rendering/Lighting/Scene/Lighting Settings/Lighting Settings Asset = ï¿½LightingSettingYouMadeï¿½(press New)
  4. Window/Rendering/Lighting/Scene/Mixed Lighting/Realtime Global Ilumination = off
  5. Window/Rendering/Lighting/Scene/ Mixed Lighting /Baked Global Ilumination = on
  6. Window/Rendering/Lighting/Scene/Lightmapping Settings/Lightmapper = Progressive GPU
  7. Window/Rendering/Lighting/Scene/Lightmapping Settings/AutoGenerate = off (press Generate Lighting as needed)
  8. Hierarchy/Post Process Volume/Global Volume/Profile (ï¿½SampleProfile or ProfileYouMadeï¿½(press New)
  9. Hierarchy/Global Volume/Overrides as desired...
  10. Hierarchy/Global Volume/Mode/Global
  11. Hierarchy/Global Volume/Profile/Make new one ï¿½ click ï¿½Newï¿½ Button
  12. Check URP Renderer: Top Menu/Edit/Project Settings/Graphics/ Scriptable Render Pipeline Settings:
    1. URP-HighFidelity (Universal Render Pipeline Asset)
  13. Check URP Renderer: Top Menu/Edit/Project Settings/Graphics/URP Global Settings:
    1. UniversalRenderPipelineGlobalSettings (Universal Render Pipeline Global Settings)
  14. Settings - How to Fix Pink Materials in Unity 2023 | Render Pipeline Basics
