Task 5.2 - Lego Widget Minifig Animation with Unity UI Buttons
5.2 Video

Open source link

  1. Use Lego character built from Mecabricks animated in Max
    1. Widget02StandWalk
    2. Stand, walk, and flip animations
  2. Import to Unity, make Animator Controller
  3. Edit Animation timeline in Inspector to create stand, walk, flip
    1. Stand - 0,0 - looping
    2. Flip - 0,20 - looping
    3. Walk - 20, 60 - looping
  4. Put animations in Animator window with Stand as Layer Default State, and Flip and Walk with transitions from Entry State
  5. Create Unity UI Button
    1. Screen space overlay
    2. In button anchors box, click to enter
    3. Hold down alt and select centre or top to snap button position
    4. Drag button to desired position with rect transform
  6. Add an on-click event for button
    1. Drag Lego minifig into exposed box
    2. Select Animator play string name option
    3. Type in name of animation from animator
  7. Test
    1. Try turning loops on and off
    2. Try combinations of buttons and scripting by using below script on the Lego Figure
