IDE Setup: Visual Studio / Script Editor

Install Visual Studio 2022 Community as the script editor (IDE) for Unity

  1. Start new Unity project
  2. Update Visual Studio Editor in Unity Package Manager if needed to 20.0.22

    https://gyazo.com/c5d2466916aa3de27604458adf7e7584

  3. Open Unity -Preferences- from top menu -Edit- and go to -External Tools- for the Script Editors List
  4. Make sure the -External Script Editor- is set to Visual Studio 2022:

    https://gyazo.com/b0e51f43c1ebcc56a844808ca740702a

  5. Test open a script by double clicking on it in Unity
