Blender Lego Minifig Tutorial - Arms and Hands

This tutorial continues modeling a LEGO-style arm starting at the wrist using circles and a Mirror modifier. It uses Blender default keymap (Tab, G, R, S, E, I, Ctrl+R, Ctrl+B, Ctrl+2, etc.). The workflow is non-destructive: use Mirror and Subdivision Surface modifiers while editing the half-mesh. Goal: create a symmetrical arm (forearm => elbow => upper arm) that connects to a torso, beginning modeling at the wrist with a circle primitive.

Save frequently

  • Press Ctrl+S regularly to save your progress.
  • Have a number at the end of your file name to increment.
  • Press the "+" and save button to increment save.

Quick shortcuts used

  • Shift+A: Add menu
  • Tab: toggle Edit/Object mode
  • G / R / S: Move / Rotate / Scale
  • X: delete
  • E: Extrude
  • I: Inset
  • F: Fill face
  • Ctrl+R: Loop Cut
  • Ctrl+B: Bevel
  • Ctrl+2: quick Subdivision Surface
  • P: Separate => Selection
  • Alt+Click: select edge loop
  • Ctrl+A: Apply transforms
  • Right-click => Shade Smooth

Step 1 - Create mirrored Arm models:

  1. Add the wrist circle (base of the arm)
    1. Shift + A => Mesh => Circle.
    2. In the lower-left Add Circle panel (or F9), set Vertices to 16 (good balance between roundness and low poly).
    3. Set Radius to 0.18m
    4. Set Location to -0.82m,-0.1m, -0.2m
    5. Set Rotation to 16.3, 6.6, 10.8
    6. Apply all Transforms
    7. Apply mirror mode

      https://gyazo.com/9a723f91c669d04f1b2c11ac24c92460

  2. Turn the circle into a short cylinder (wrist thickness)
    1. Tab => Enter Edit Mode.
    2. With all vertices selected (A), press F to Fill the circle (creates a face).
    3. With the top rim of the newly created wrist cylinder selected (edge loop or face), press E to extrude along the arm axis to near the elbow.
    4. Extrude (E) to create elbow region and upper arm segments. Use smaller extrudes rotation and and scaling to form joints.

      https://gyazo.com/768ee7ed80b20e382626bfc876e74084

  3. Work on half the arm (edit only one side)
    1. Tab => Edit Mode (you will only edit one side because of Mirror).
    2. Use edge/face/vertex select modes (1/2/3) to shape the half-arm:
      1. Add loop cuts where you want definition: Ctrl+R => click => right-click to keep centered.
      2. S => Z => 0 can flatten faces if you need a planar surface (useful on inner surfaces).
    3. To create a visible elbow, extrude a short segment then scale inward, then extrude again to continue the upper arm.
    4. Add some bend before the elbow by adding a Loop with Shift+R
    5. Rotate Loop and move into place
    6. Do final vertex adjustments with Proportional adjustment to smooth differences - Press O and scale vertice effect with mouse wheel before moving.
    7. Try a local rotation of the shoulder loop to avoid line twisting along upper arm. Local selection is in the top view menu. Don-t forget to change it back to global after the adjustment. You will Alt+LMB to select the shoulder loop and R+Z to rotate in local.

      https://gyazo.com/cd289cb947e0cf3877e2d5d7e9d65a9b

      https://gyazo.com/0b951c02e03f04f82db4e5f9dc6c7349

      https://gyazo.com/820097cc3a8e9e16fb2fcc64954354f1

  4. Bevel Shoulder
    1. Double check that the shoulder loop is perpendicular to the upper arm, and topology is not twisted
    2. Rotate in X to fine tune
    3. Ctrl-B and Mouse wheel to bevel to reference in both sides.
    4. This may cause some overlap at the top. This can be deleted and filled later. The important part is the shape.

      https://gyazo.com/1a6a748c489f5eefc7892d72c15152a2

  5. Add topology control: bevels and supporting loops
    1. Select an edge loop near each joint or shoulder area (Alt+Click on an edge).
    2. Ctrl+B to bevel; drag to set bevel width; roll the mouse wheel to increase segments (1-3 segments).
    3. Use Ctrl+R to add supporting loops close to hard edges to control how Subdivision Surface smooths the silhouette (typical offset 0.02-0.05 Blender units).
    4. If you have a messy end loop, select with Alt+LMB and Press M=>at center to merge the vertices

      https://gyazo.com/deea05ee80f23e425074e9216ecec75c

      https://gyazo.com/c7194e73e4fd726f02c450742168d68c

      https://gyazo.com/b4d5c822b838785ed2443808b719f8f9

e. Use proportional editor to Move Rotate and scale down a hard edge for the Arm against the body.

f. Enable Proportional Editing: Press the O key or click the Proportional Editing icon (a circle) in the 3D Viewport header.

g. Select and Transform: Go into Edit Mode, select the vertices, edges, or f aces you want to move, and transform tools like Grab, Rotate, Scale

h. Adjust the influence: Use the scroll wheel to increase or decrease the size of the circle, determining how far the proportional effect extends.

https://gyazo.com/bee841c0ae59ab2041ea045b9ff553d3

  1. Add details (hand peg, wrist connector)
    1. If the arm needs a peg to connect to a hand or wrist joint:
      1. Select the wrist end face, I (Inset) => type 0.08 => Enter to inset a small circle.
      2. Extrude this back into the arm, do a very close inset.
      3. E => extrude a short peg

        https://gyazo.com/e5a896e17b78729163b840c6f88f8285

  2. Model a simple hand
    1. Front view (Y) in Edit mode for Existing arm object
    2. Add circle with 16 vertices, 0,22 radius, Location -0.875,0, -0.525 and with a 90 degree X rotation typed into the box when created with Ctrl+A
    3. Position in side view in Y
    4. Extrude in side view for depth
    5. In Edit 2 mode, hover over a press L t select all faces, Extrude and Scale inwards to make thickness in the front view - .6 for X and Z, keep Y at 1.0 - adjust in box at bottom
    6. Delete and adjust vertices to fit reference, add edge loops to make sharper edges for subdivision smoothing and shaping.

      https://gyazo.com/b7159ece00be148f69d2ea346cd7cd3d

      https://gyazo.com/8fb34d166fb36f4b5c0b2bebb6f5b029

  3. Separate Arm and Hand parts if needed (as with Legs earlier)
    1. To make the forearm or hand a separate object (for animation or clarity):
      1. In Object mode apply modifier
      2. Select the faces for that piece, press P => Selection to separate into a new object.
      3. Tab => Object Mode, select that new object and add its own Mirror/Subsurf modifiers if needed.
  4. Smooth and subdivide
    1. Tab => Object Mode.
    2. Ctrl + 2 to add Subdivision Surface (viewport level 2) and smooth the shape.
    3. Right-click => Shade Smooth.
    4. If surfaces become too soft, return to Edit Mode and add supporting loop cuts or adjust bevel widths.
  5. Cleanup and final transforms
    1. Object Mode => Ctrl + A => Apply Rotation & Scale to avoid issues with subsequent modifiers.
    2. Check normals (Edit Mode => A => Mesh => Normals => Recalculate Outside or Shift+N) if shading looks odd.
    3. Merge any duplicated vertices at the mirror seam if needed (they should auto-merge when Clipping is enabled).
  6. Optional: convert circle-based wrist to cylinder for perfect rounds
    1. If you need a perfectly circular wrist peg, instead of inset/extrude, add:
      1. Shift + A => Mesh => Cylinder (16 verts), rotate and position it at wrist, then Boolean/Join or integrate with arm geometry.
    2. Use Boolean carefully; clean up topology afterward (Merge by Distance / retopology).

Notes & tips

  • Start small: use low-poly circles (16 verts) and only add loops when needed. This keeps topology clean.
  • Mirror Clipping: ensure center vertices lie exactly on the mirror plane (X=0) for a clean seam.
  • Axis orientation: the tutorial assumes the arm extends along one scene axis (Y recommended). Adjust R/X/Y/Z constraints accordingly.
  • Use numeric extrude values for consistent segment lengths (e.g., E => Y => 0.20).
  • Keep quads where possible; avoid unnecessary n-gons around joints for easier smoothing.
  • Use Ctrl+A => Apply Scale early if modeling in Object Mode then editing; it prevents unpredictable bevel/scale behavior.

Example quick keystrokes (summary)

  1. Shift+A => Mesh => Circle (Verts:16) => R X 90 => G to wrist position
  2. Tab => Edit Mode => A => F => E Z 0.06 => S 0.9
  3. Select top rim => E Y 0.20 => S 0.95 (forearm)
  4. Repeat extrudes (E Y 0.18) and scale to make elbow + upper arm
  5. Tab => Object Mode => Modifiers => Add Mirror => Clipping ON
  6. Tab => Edit Mode => Ctrl+R (add supporting loops) => Ctrl+B (bevel edges)
  7. Tab => Object Mode => Ctrl+2 => Right-click => Shade Smooth
  8. Ctrl+A => Apply Rotation & Scale
