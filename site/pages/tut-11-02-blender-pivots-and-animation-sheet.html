Prepare & Animate a LEGO Minifigure in Blender

Overview

  • Goal: clean origins, parent parts into a simple hierarchy, create an "up/down" empty controller, lock axes to limit motion, key a 1-30 run loop, add a 10-frame standing pose, and refine interpolation for a snappy run.
  • Keep names consistent (e.g., Body, LeftLeg, RightLeg, LeftArm, RightArm, Head, UPctrl).

FBX Export

  1. Right click on Empty object controller and select Hierarchy
  2. File/Export Fbx
  3. Use settings Below:
    1. Include
      1. Limit To: Click on Selected Objects
      2. Object Types: Click on Mesh,
      3. Object Types: Shift Click to select Empty and Armature as well
    2. Transform
      1. Apply Scalings: All Local
      2. Forward: -Z Forward
      3. Up: Y Up
      4. Tick Apply Unit
      5. Tick Use Space Transform
    3. Geometry: Apply Modifiers
    4. Armature
      1. Tick Only Deform Bones
      2. Untick Add Leaf Bones
    5. Animation
      1. Tick Key all Bones
      2. Untick NLA Strips
      3. Tick Force Start/End Keying
  4. Export Fbx
  5. Import to Unity and setup animation as normal

Quick Troubleshooting & Best Practices

  • Accidental origin offsets: fix with Object ? Set Origin ? Origin to Geometry.
  • Rigid-body or modifier issues: origin acts as center; set origin properly before using physics/mirror.
  • Use naming conventions and collections to avoid selecting wrong objects in other views.
  • Lock channels to limit accidental translation/rotation (N panel ? Item ? lock icons).
  • Keep UPctrl clean (zeroed transforms) and use it as the main animation parent for world movement.
