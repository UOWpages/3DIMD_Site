Unity Animator Controller

Unity Animator Controller

The Animator Controller controls animation through layers with state machines, controlled by parameters.

The Animator Component is added to an object to be animated.

It acts as a constructor

Variables

Variables:

Layers – Layers of animations in the controller window.

The Layer has a visual State Machine that controls the model’s animations

Parameters – expose control by script (Speed), transitions and blendtrees

Transitions, Masks, Logic and Booleans

Animator Component in a Game Object has:
