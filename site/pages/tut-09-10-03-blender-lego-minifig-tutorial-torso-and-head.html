Blender Lego Minifig Tutorial - Torso and Head

This document provides a Blender workflow to model a Lego style torso, including numeric dimensions (Blender units) and exact keys to press or values to type

Core Principles

Workspaces

Work with a Y forward front view and an X forward side view in Layout Workspace, and a perspective view in Modeling Workspace:

Save frequently

  • Press Ctrl+S regularly to save your progress.
  • Have a number at the end of your file name to increment.
  • Press the "+" and save button to increment save.

Step 2 — Make Body with Mirror and Bevel
  1. Edit Mode > Edge select (2)
  2. Use Ctrl+R to add loop cuts where you need more geometry down center of body.
  3. LMB Click to create the cut down Z axis (center) , then right-click to leave it centered.
  4. Edit Mode > Vertex Select (1) and LMB box select verts on left side of cube, delete
  5. Object Mode > In the Properties (right panel) => Modifiers (wrench icon) => Add Modifier => Mirror (defaults to X). Enable additional axes if needed.
  6. Turn on Clipping so mirrored halves stay welded at the centerline.
  7. Edit Mode > Vertex Select (1) LMB box select and drag in Top vertices to make shoulders
  8. Shift Select Edges and press Ctrl+B to bevel. Move the mouse to set width and use the mouse wheel to set the number of segments for roundness.
  9. For softer shading, add a Subdivision Surface (Ctrl+2) and right-click => Shade Smooth. (in object mode)

Step 5 - Neck and Detail Shaping
  1. Select the bottom neck face
  2. extrude neck face down into body(S and Z to limit in axis).
  3. Select top face, extrude and scale in Z to peg height (E, Z)
  4. Inset top peg face / extrude down for the peg detail.
  5. Use Alt+Click to select edge loops and CTRL+B to bevel for smoother transitions.
  6. Peg top and bottom can be selected at same time in edge (2) alt click and ctrl b to bevel. scroll wheel, refine with scale
  7. smooth as before in object mode - add a Subdivision Surface (Ctrl+2) and right-click => Shade Smooth. (in object mode)
  8. Subdivision can be seen in the settings Editor Type menu
  9. insert another face with I and scale it down with S in the peg hole bottom if needed to help subdivision.

Tips and Workflows:

Sharpen/drop supporting loops for Subdivision

  1. Edge select (2)
  2. Alt + Click edge near corner to select loop
  3. Ctrl + R => add loop near that edge for support: Left-click => drag closer to the corner => Left-click to confirm
  4. Repeat on top/bottom to keep silhouette crisp. Typical distances: 0.02–0.05 Blender units from the main edge.

Add Subdivision Surface and smoothing

  1. Tab => change to Object Mode
  2. Ctrl + 2 => Applies a Subdivision Surface modifier set to level 2 in viewport
  3. Right-click on the object => Shade Smooth
  4. Properties => Object Data (triangle icon) => Normals => enable Auto Smooth if needed (angle 30°–60°)

Final cleanup & apply transforms - Normalising

To normalize an object's scale in Blender, select the object in Object Mode and press Ctrl + A, then choose Scale from the menu. This applies the current scale to the object, resetting the scale factor to \(1,1,1\) without changing the object's visual size or appearance. This is important for correct texture mapping and modifier behavior. To normalize scale and rotation of parented objects, select all objects, use Alt+P > Clear and Keep Transformation, then use Ctrl+A > Rotation & Scale.

  1. If bevels or other tools behave oddly after scaling in Object Mode, apply transforms: Object Mode => Ctrl+A => Apply Scale/Rotation.
  2. Re-apply loop cuts and bevels after applying transforms if needed.
  3. If you used Mirror and are satisfied, in Modifiers tab click Apply on Mirror (optional) and Subdivision (only if you need to export).
Notes & Shortcuts:
  • Tab: toggle Edit/Object mode
  • G, R, S: move, rotate, scale
  • 1/2/3 keys: vertex/edge/face selection modes
  • Ctrl+R: loop cut; click then right-click to keep centered
  • Ctrl+B: bevel edges; mouse wheel to increase segments
  • Ctrl+2: quick Subdivision Surface level
  • X => Faces: delete faces
  • I: inset; E: extrude; P => Selection: separate
  • Ctrl+A: apply transforms (important after object-mode scaling)
