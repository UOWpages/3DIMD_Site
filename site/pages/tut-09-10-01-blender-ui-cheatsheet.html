Blender UI CheatSheet

A beginner's guide to Blender's interface, navigation, object manipulation and mesh modelling, followed by a practical workflow and a quick-reference cheatsheet. Shortcuts assume Blender's default keymap; place the mouse pointer over the relevant editor before using them.

1. Blender Interface & Navigation

First learn where Blender's tools are located and how to move your view without moving the objects in your scene.

Main editors, workspaces & window layout

Recognise the main parts of Blender

  • 3D Viewport: the main area for viewing, selecting, transforming and modelling objects.
  • Outliner: lists scene objects and collections; use it to select, rename, organise and control visibility.
  • Properties Editor: contextual settings for objects, modifiers, materials, mesh data, constraints and rendering.
  • Toolbar: tools at the left of the Viewport (toggle with T).
  • Sidebar: View, Tool and Item panels, including numeric transforms (toggle with N).
  • Viewport header: mode, snapping, pivot, overlays, gizmos and viewport shading controls.
  • Timeline: playback and animation controls, normally along the bottom of the Layout workspace.
  • Other editors: UV Editor, Shader Editor and others become useful later in the workflow.

Workspaces and arranging editors

Layout is a good starting workspace; Modelling provides a modelling-focused arrangement. You can change an area's editor type using its top-left editor selector. To split or join editor areas, drag from an area corner and choose the intended arrangement. This changes the workspace layout, not your model.

Beginner tip: If a shortcut seems not to work, check which editor your mouse is over and whether you are in Object Mode or Edit Mode.

Change how the model is displayed

  • Viewport shading: Z opens the shading pie menu: Wireframe, Solid, Material Preview and Rendered.
  • Overlays: toggle guides such as grid, origins, face orientation and normals in the Viewport header.
  • X-Ray: see and select through geometry (toggle with Alt+Z in the default keymap).
  • Gizmos: show on-screen move/rotate/scale handles; toggle from the Viewport header.
  • Shade Smooth / Shade Flat: adjust the appearance of surface shading without necessarily adding polygons. These do not replace geometric detail.

Remember: orbiting, panning and zooming change your view; G, R and S change the selected object or geometry.

2. Objects, Selection & Transformations

Understand what is selected, which mode you are in, and how Blender decides the centre and direction of a transformation.

Object Mode, Edit Mode & selection

Two essential modes

  • Object Mode: select and transform entire objects, organise them, and add modifiers. An object's origin moves when the object moves.
  • Edit Mode: change the vertices, edges and faces inside a mesh. Moving geometry does not automatically move the object's origin.
  • Tab: switch between Object Mode and Edit Mode for a mesh.
  • 1 / 2 / 3: vertex / edge / face selection in Edit Mode (the number row, not the numpad).

Selection controls

  • A select all; Alt+A deselect all; B box select; C circle select.
  • L select linked mesh geometry under the pointer in Edit Mode; Ctrl+L select geometry linked to the current selection.
  • Alt+Click on an edge to select a loop; Ctrl+Alt+Click for an edge ring (behaviour can depend on selection mode and keymap).
  • Blender distinguishes selected objects from the active object (typically highlighted differently). Some operations use the active object as their reference.
  • Shift+A adds objects in Object Mode, or geometry to the active mesh in Edit Mode. Shift+D duplicates; X deletes.
Move, rotate, scale & applying transforms

One pattern for three transformations

Select an object or mesh component, press a transformation key, optionally constrain an axis, enter a number, then press Enter to confirm (or Esc to cancel).

ActionShortcutExample
Move (Grab)GG → X → 2 moves 2 units along X
RotateRR → Z → 90 rotates 90° around Z
ScaleSS → Z → 2 doubles scale along Z
  • X, Y, Z constrain the operation to an axis. Pressing an axis key twice can use the corresponding local axis when applicable.
  • Hold Shift during a transform for finer adjustment; use the N sidebar for exact values.
  • Global axes refer to the scene; Local axes follow the object's orientation. Other orientations include Normal and View.
  • Pressing R twice invokes trackball rotation; it is not required for a normal axis-constrained rotation.

Apply versus clear transforms

In Object Mode, Ctrl+A opens Apply. Applying rotation or scale makes the current appearance the new baseline (rotation becomes 0° and/or scale becomes 1) while preserving the visible result. It is often useful before some modifiers, physics setups or export, but should be deliberate: applying location also changes how the object's origin and coordinates are represented.

Clear is different: Alt+G clears location, Alt+R clears rotation, and Alt+S clears scale in Object Mode. In mesh Edit Mode, Alt+S is Shrink/Fatten. Always check the current mode.

Origins, pivot points & the 3D Cursor

Origin is not the same as pivot

  • Object origin: an object's reference point, shown as an orange dot when origins are visible. It influences object transforms, parenting and certain modifiers (such as Mirror).
  • Transform pivot: the centre used when rotating or scaling a selection. It can be an object origin, the median of selected elements, the 3D Cursor or another pivot mode.
  • Physics centre of mass: a separate physical concept; it is not automatically identical to the object origin in every physics system.

Common pivot modes

PivotEffect
Median PointCentre derived from the selection; useful for transforming objects together
Individual OriginsEach selected object or element uses its own centre
3D CursorUses the 3D Cursor's position as the centre
Bounding Box CenterCentre of the selection's bounding box
Active ElementUses the active object or component as the reference

Find and position the origin

  • Set Origin: in Object Mode, use Object → Set Origin, including Origin to Geometry, Origin to 3D Cursor and Geometry to Origin.
  • 3D Cursor: use Shift+S for snapping options such as Cursor to Selected, Selection to Cursor and Cursor to World Origin.
  • Show origins: use the Viewport Overlays controls when checking where origins are positioned.
  • Precise origin placement: in Edit Mode select a vertex → Shift+S → Cursor to Selected → return to Object Mode → Object → Set Origin → Origin to 3D Cursor.

Example: to scale several objects around their own centres, select them, set Pivot to Individual Origins, then press S. For a door or hinged part, position its origin at the hinge before rotating it.

3. Mesh Modelling Tools

A mesh is made of vertices (points), edges (connections) and faces (surfaces). Most direct modelling happens in Edit Mode.

Essential modelling operations
ToolShortcutWhat it does
ExtrudeEExtends selected geometry to create new connected geometry
Inset FacesICreates an inset boundary inside selected face(s)
Loop CutCtrl+RAdds edge loops through suitable quad topology; right-click after choosing a cut to centre it
BevelCtrl+BRounds or chamfers selected edges; mouse wheel adjusts segments
Make Face / FillFCreates a face or fills suitable selected boundaries
MergeMMerges selected vertices using a chosen method
Delete / DissolveXChoose whether to remove vertices, edges, faces or dissolve geometry
SeparatePSeparates selected mesh geometry into another object

Try it: Add a cube, enter Edit Mode, switch to face selection (3), select its top face and press E to extrude it upward. Press I to inset the new top face.

Precision, snapping & additional tools

Precision tools

  • Snapping: Shift+Tab toggles snapping; choose Increment, Vertex, Edge, Face and other targets from the header. Holding Ctrl during a transform can temporarily invert the snap state.
  • Proportional Editing: O toggles soft influence over nearby geometry. Adjust the influence radius with the mouse wheel during a transform.
  • Numeric input: combine G, R or S with an axis and number for repeatable modelling.

Additional tools to explore later

  • Knife: K manually cuts geometry; confirm with Enter.
  • Rip: V splits connected mesh geometry at a selection.
  • Slide: G then G slides an eligible vertex or edge along surrounding geometry.
  • Merge by Distance: under Mesh → Clean Up, merges vertices within a specified distance.
  • Convert tris to quads: Alt+J where suitable geometry is selected.

Topology tip: quads are often easier to edit and subdivide predictably. Triangles and n-gons are not always wrong, but require more care near deformation and subdivision.

4. Modifiers & Model Organisation

Modifiers provide non-destructive ways to alter a model. Scene organisation helps you keep the result manageable.

Modifiers & non-destructive modelling
ModifierTypical useWatch for
MirrorBuild symmetrical shapesMirror plane follows the object's origin or a specified Mirror Object; Clipping helps prevent crossing the mirror plane
Subdivision SurfaceRefine and smooth a meshSupporting loops help preserve sharper features; Ctrl+2 sets a subdivision modifier level, not applies it
BooleanCut, combine or intersect formsInspect and clean topology afterward where needed
BevelRound hard edges non-destructivelyUnapplied non-uniform scale may affect the result
SolidifyAdd thickness to surfacesCheck normals and thickness direction
ArrayRepeat geometry in a patternCheck offset direction and spacing

Modifier order matters: the stack is evaluated from top to bottom, so changing the order can change the result. Keep modifiers editable until you have a reason to apply them.

Important: apply rotation and scale when a modifier or export workflow requires it, rather than automatically applying every transform on every object.

Outliner, collections & cleanup
  • Outliner: rename objects clearly, inspect the scene hierarchy and control visibility, selection restrictions and rendering using available restriction toggles.
  • Collections: organise related objects without merging their meshes. In Object Mode, M moves selected objects to a collection.
  • Join: Ctrl+J combines selected compatible objects into one object in Object Mode; this differs from putting objects in a collection.
  • Separate: P in Edit Mode separates selected geometry into a new object.
  • Cleanup: Mesh → Clean Up includes Merge by Distance and Delete Loose. After Boolean operations, inspect overlapping vertices and unintended faces.
  • Save versions: use File → Save As or incremental filenames such as model_v01.blend, model_v02.blend.

Later productivity options: right-click context menus, toolbar settings, custom keymaps and optional add-ons can accelerate work. Check availability and compatibility with the Blender version installed before following an add-on tutorial.

5. Practical Workflow & Best Practices
Guided exercise: box model a simple prop

Goal: create a simple stepped prop using the tools introduced above. Save the result as a .blend project.

  1. Start: select the default cube in Object Mode. Orbit with MMB, then return to a front or top view using the numpad.
  2. Shape: press Tab for Edit Mode, then 3 for face selection. Select the top face.
  3. Extrude: press E and move upward; enter a number for a controlled height.
  4. Inset: press I on the new top face to create a border.
  5. Refine: bevel suitable edges with Ctrl+B or add supporting loops with Ctrl+R where the topology permits.
  6. Inspect: return to Object Mode. Compare Solid and Wireframe shading and orbit around the result.
  7. Organise: rename the object in the Outliner, optionally move it into a collection, and save the .blend file.

Extension: experiment with a Mirror modifier and compare Median Point with Individual Origins when transforming duplicated objects.

Common problems & final checklist

Common problems

ProblemWhat to check
Shortcut behaves unexpectedlyCurrent editor, active selection, Object/Edit Mode and keymap
Object rotates around an unexpected pointPivot mode, object origin and 3D Cursor position
Origin no longer sits inside the meshGeometry may have moved in Edit Mode; consider Object → Set Origin → Origin to Geometry
Mirror modifier is offsetObject origin, mirror axis and optional Mirror Object
Bevel or other modifier looks unevenNon-uniform object scale, topology and modifier order
Physics behaves unexpectedlyObject transforms, collider geometry and centre-of-mass settings in the target physics system
Selection passes through the modelWhether X-Ray or Wireframe mode is enabled

Before finishing

  • Check the correct mode and active object before editing.
  • Use axis constraints and numeric input for precision.
  • Choose an appropriate origin for moving, rotating or exporting a prop.
  • Inspect topology and normals; use supporting loops where subdivision requires them.
  • Keep modifiers editable while exploring alternatives.
  • Name objects, organise collections and save versions regularly.
  • For Unity or other exports, check the destination application's scale, axes, pivot and collider requirements before applying transforms or exporting.
