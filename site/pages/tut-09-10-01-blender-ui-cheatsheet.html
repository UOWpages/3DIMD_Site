Blender - Origins & Pivot Points

OnePage CheatSheet

Quick concepts
  • Origin = object property (orange dot):

reference for location/rotation/scale and centerofmass for physics & some modifiers.

  • Pivot point = transform center used when rotating/scaling selections;

one pivot option can be the object origin.

  • Object Mode moves object + origin
  • Edit Mode moves geometry only (origin stays).
Where to find things
  • Object > Set Origin ? Origin to Geometry / Origin to 3D Cursor / Geometry to Origin
  • 3D Viewport header ? Transform Pivot Point menu (icon near snapping/overlay controls)
  • Overlays ? Show Origins (toggle visibility)
  • Shift+S ? Snap menu (Cursor to Selected / Selection to Cursor / Cursor to World Origin)
Common Pivot Modes (short)
  • Median Point - average/median of selection (Objects: median of origins. Edit mode: median of selected components).
  • Individual Origins - each object/component transforms around its own origin.
  • 3D Cursor - pivot placed at 3D Cursor position.
  • Bounding Box Center - center of bounding box enclosing selection (worldaxis aligned).
  • Active Element - pivot at the active (lastselected) object/component.
Essential Keystrokes
  • Tab - toggle Object / Edit Mode
  • G / R / S - Grab / Rotate / Scale
  • Ctrl+A - Apply (Location / Rotation / Scale) (Reset, Normalise)
  • Alt+G - Clear Location
  • Alt+R - Clear Rotation
  • Alt+S - Clear Scale
  • Shift+S ? Cursor to Selected / Selection to Cursor / Cursor to World Origin
  • Shift + RightClick (or Shift + LeftClick if leftclick select) - place 3D Cursor interactively
  • Object > Set Origin > ... - use menu to move origin or geometry
Quick fixes & reminders
  • Origin moved unexpectedly (mesh moved in Edit Mode): Object > Set Origin > Origin to Geometry to recenter origin to mesh.
  • Physics weirdness (tipping / offcenter mass): origin - center of mass ? set origin to geometry.
  • Mirror modifier seems off: mirror uses object origin as mirror center ? move origin or switch mirror object/axis.
  • Want group to rotate as one: choose Median Point or Bounding Box Center. Want each to scale separately: Individual Origins.
  • Apply transforms before exporting or using some modifiers: Select object ? Ctrl+A ? Apply Rotation & Scale (and Location if appropriate).
Best practices
  • Decide an origin convention for your project (center for prop physics, base for hinged parts, handle for animatable pieces) and stick to it.
  • Use Shift+S and 3D Cursor for precise origin placement.
  • Toggle Overlays ? Origins when debugging transforms, physics, or modifiers.
  • Apply transforms (Ctrl+A) when you want current pose to be the -zero- state (especially before parenting, exporting, or physics setup).
Oneline reminders
  • To set origin to a precise vertex/point: Edit Mode ? select vertex ? Shift+S ? Cursor to Selected ? Tab to Object ? Object > Set Origin > Origin to 3D Cursor.
  • To make many objects scale individually: Select objects ? Pivot = Individual Origins ? S.

Layout / Main editors
  • 3D Viewport: Primary workspace for modeling (navigation, select, transform, sculpting preview). Most modeling actions happen here.
  • Outliner: Scene hierarchy - shows objects and collections; use it to hide/lock/select objects and organize your scene.
  • Properties Editor: Contextual panels (Editor Type) for Object, Modifier, Mesh Data, Material, Object Constraints, Render settings, etc. Modifiers (Mirror, Subsurf, Boolean, Bevel) live here.
  • Sidebar (N): View / Tool / Item panels with transform values, tool options, and viewport display toggles.
  • Toolbar (left of 3D View): Quick access to tools (Move, Rotate, Scale, Transform, Extrude, Knife, Loop Cut). Can be hidden (T).
  • Top Info Bar / Header: Contains Add menu, current mode, snapping, pivot, overlays, shading, and global settings.
  • Workspaces - I tend to work in Layout with Xray and all coordinate views, and switch to Modelling for shaded and final view.
  • UV/Image Editor, Shader Editor, and other editors are available when working on UVs/materials - often used after base modeling.
Windows
  • Go to top corner of a window to get a -+- sign
  • This can be dragged down to form a new window.
  • Dragging this across an existing window give the option to split it.
  • It can also be dragged into an existing window to join them.
Modes and selection
  • Object Mode: Move/scale/rotate whole objects, add modifiers, manage collections.
  • Edit Mode: Polygon/edge/vertex-level modeling. Toggle with Tab.
  • Selection types: Vertex/Edge/Face (1 / 2 / 3 keys or icons). Use Alt+Click to select an edge loop, Ctrl+Alt+Click to select ring loops (keymap dependent).
  • Lasso/Box/Circle select: Ctrl/Cmd + drag tools or B (box), C (circle), Lasso from the tool shelf.
Transforms & navigation
  • Navigation: Middle mouse drag to orbit, Shift+MMB to pan, scroll to zoom (or Numpad keys for orthographic views).
  • Move/Rotate/Scale: G / R / S. Constrain axes with X / Y / Z (e.g., G ? Z). Type numerical values after the shortcut.
  • Precision: Hold Shift for fine control. Use axis constraints and orientation (Global, Local, Normal, View).
  • Apply transforms: Object Mode ? Ctrl+A ? Apply Location/Rotation/Scale (important before some modeling ops).
Common Edit Mode tools & operations
  • Extrude: E (faces/verts/edges)
  • Inset faces: I
  • Bevel: Ctrl+B (edges), use mouse wheel to add segments
  • Loop cut: Ctrl+R (LMB click to place, right-click to center)
  • Merge vertices: M (or Alt+M in some keymaps)
  • Fill / Make face: F
  • Delete: X (choose vertices/edges/faces)
  • Separate: P ? Selection (make new object)
  • Knife: K for manual cuts
  • Rip / Rip fill: V (depending on keymap)
  • Edge slide / vertex slide: G then G (or use dedicated tools)
  • Snap: Shift+Tab toggles snapping (Vertex, Edge, Face, Increment). Use Ctrl while transforming for temporary snap.
  • Proportional Editing: O to toggle; mouse wheel changes falloff radius for soft transforms.
Modifiers & non-destructive workflow
  • Mirror: Symmetry across axis; enable Clipping to merge at center.
  • Subdivision Surface: Smooths geometry (add as modifier; use supporting loops to keep edges sharp).
  • Boolean: For cutting/combining complex shapes (prefer robust workflows: signed booleans, clean topology after operation).
  • Bevel, Solidify, Array: Common modeling helpers.
  • Order matters: modifier stack is applied top?bottom; move modifiers to get desired results.
  • Use separate objects (P) or collections for components you want to edit independently.
Viewport display & shading
  • Shading modes: Wireframe (Z?Wireframe), Solid, Material Preview, Rendered.
  • Overlays: Toggle visibility of gizmos, face orientation, normals, origins, grid, etc.
  • Shade Smooth / Shade Flat: Right-click ? Shade Smooth for a smoothed normal look; add supporting loops for sharpness.
  • X-Ray / X-Ray toggle: Makes selecting through geometry easier (Z menu or X-Ray slider).
  • Show Gizmo, Show Overlays, Toggle Xray and ViewPort Shading is ideal for modeling
  • Z plus wheel menu for Wireframe, Solid toggling
Outliner & scene organization
  • Collections: Group objects for visibility, selection, rendering control.
  • Lock selectability / visibility / renderability per object or collection to avoid accidental edits.
Useful shortcuts (quick reference)
  • Tab: Toggle Object/Edit Mode
  • Shift-A: Add Object Primitives
  • G / R / S: Move / Rotate / Scale
  • Ctrl+R: Loop Cut
  • Ctrl+B: Bevel
  • E: Extrude
  • I: Inset
  • F: Fill face
  • X (or Delete): Remove elements
  • Shift+D: Duplicate (right-click to keep in place)
  • M: Move to Collection (or Merge depending on keymap)
  • O: Toggle Proportional Editing
  • Shift+Tab: Toggle Snapping
  • Ctrl+A: Apply transforms
  • 1/2/3: Vertex/Edge/Face select
Modeling tips & best practices
  • Move in one axis at a time
  • Check whether in Object or Edit mode when adding objects.
  • Work non-destructively: use modifiers before applying them so you can iterate.
  • Apply transforms (Ctrl+A) before using modifiers, boolean ops, or bevels to avoid skewed results.
  • Keep quad-based topology where possible; avoid n-gons in deforming areas.
  • Use supporting edge loops to control sharpness when using Subdivision Surface.
  • Clean up after booleans: merge vertices, remove doubles (Merge by Distance), and retopologize if needed.
  • Organize into collections and name objects clearly.
  • Save versions frequently and use incremental saves (file_v01.blend, etc.).
Customizing & productivity
  • Pie menus (add-on) and custom keymaps can speed modeling.
  • Tool settings in the toolbar and the topbar let you fine-tune tools without memorizing all shortcuts.
  • Learn context menus (right-click) - they expose commonly used operations quickly.
  • Enable addons like LoopTools, F2, and Mesh: Extra Tools for faster workflows.
Blender UI CheatSheet

Quick reference for modeling in Blender (Default Keymap)

Windows
  • Go to top corner of a window to get a -+- sign
  • This can be dragged down to form a new window.
  • Dragging this across an existing window give the option to split it.
  • It can also be dragged into an existing window to join them.
Modes & Navigation
  • Tab: Toggle Object/Edit Mode
  • 1 / 2 / 3: Vertex / Edge / Face select (Edit Mode)
  • Middle Mouse Button (MMB): Orbit
  • Shift + MMB: Pan
  • Scroll Wheel: Zoom
  • Numpad 1 / 3 / 7: Front / Right / Top orthographic views
  • Ctrl + Numpad 1/3/7: Opposite view
  • Numpad 5: Toggle perspective / orthographic
Transform Basics
  • G: Grab / Move ? then X / Y / Z to constrain (e.g., G ? Z)
  • R: Rotate ? R ? X/Y/Z to constrain
  • S: Scale ? S ? X/Y/Z to constrain
  • Shift (hold): finer control when transforming
  • Ctrl + A (Object Mode): Apply ? Location / Rotation / Scale
Selection Tools
  • A: Select all / deselect all
  • B: Box Select (or LMB and drag)
  • C: Circle Select
  • L: Select linked (hover then L)
  • Alt + Click (edge): Select edge loop
  • Ctrl + Alt + Click (edge): Select edge ring (keymap dependent)
  • Ctrl + L: Select linked geometry under cursor
Modeling Operations (Edit Mode)
  • E: Extrude (faces/edges/verts)
  • I: Inset faces
  • F: Make face / fill
  • Ctrl + R: Loop Cut (click, then move; right-click to center)
  • Ctrl + B: Bevel (edges) - mouse wheel to add segments
  • X / Delete: Delete (choose Vertices / Edges / Faces / Only Faces / Edges & Faces)
  • M: Merge (or Move to collection in Object Mode)
  • P: Separate ? Selection (make new object)
  • K: Knife tool (click to cut; Enter to confirm)
  • V: Rip (separate verts) / (depends on keymap)
  • Alt + M (or M in some keymaps): Merge vertices by center / at cursor
Proportional Editing
  • O: Toggle Proportional Editing
  • Mouse wheel: change influence radius while transforming
Snapping
  • Shift + Tab: Toggle Snapping
  • Hold Ctrl while transforming: temporary snap
  • Snap types: Vertex / Edge / Face / Increment (set in header)
Modifiers (non-destructive workflow)
  • Mirror: Add Modifier ? Mirror (enable Clipping to weld center)
  • Subdivision Surface (Subsurf): Smooth geometry; use supporting loops to keep edges crisp
  • Boolean: Add Modifier ? Boolean (use carefully; clean topology after)
  • Bevel, Solidify, Array: common helpers
  • Order matters: modifiers apply top ? bottom in the stack
Shading & Viewport
  • Z: Quick shading pie (Wireframe, Solid, Material Preview, Rendered)
  • Right-click ? Shade Smooth / Shade Flat
  • Overlays (top-right in 3D View): toggle face orientation, normals, grid, origins
  • X-Ray / X-Ray slider: select through geometry
  • Show Gizmo, Show Overlays, Toggle Xray and ViewPort Shading is ideal for modeling
Outliner & Scene Management
  • Collections: Group objects for visibility / render
  • Select Filter for Restriction toggles (icons in Outliner for below)
  • Click icons in Outliner to toggle Visibility / Selectability / Render
  • Rename objects (double-click in Outliner) - keep names clear
Common Cleanup & Tools
  • Ctrl + J: Join selected objects
  • Alt + J: Convert tris?quads (if available)
  • Mesh ? Clean Up: Merge by Distance (remove doubles), Delete Loose, etc.
  • Ctrl + Shift + R / Ctrl + 2/3: Quick Subdivision shortcuts (Ctrl+2 = add Subsurf level + apply visually)
Quick Workflow (Box Modeling ? Refine ? Detail)
  1. Block out main forms using primitives (Cube, Cylinder, Sphere).
  2. Add Mirror modifier for symmetry.
  3. Use Loop Cuts (Ctrl+R) to add detail loops where needed.
  4. Bevel (Ctrl+B) or add supporting loops to control edge sharpness.
  5. Add Subdivision Surface and Shade Smooth for preview.
  6. Add fine details last; apply boolean only when necessary and retopologize afterwards.
Useful Shortcuts (compact)
  • Tab (Object/Edit), G (Translate), R (Rotate), S(Scale), E (Extrude), I(Insert), F, Ctrl+R (Loops), Ctrl+B (Bevel), Shift+D (Duplicate), X (Delete), P (Separate), Ctrl+A (Apply transforms), O (Proportional editing), Shift+Tab (snap)
Tips & Best Practices
  • Keep quads for clean deformation and subdivision.
  • Work non-destructively: use modifiers; apply only when necessary.
  • Apply transforms (Ctrl+A) before boolean/bevel to avoid issues.
  • Use supporting loops for sharp edges under Subsurf.
  • Organize into collections and name objects clearly.
  • Save incrementally (model_v01.blend, model_v02.blend).
