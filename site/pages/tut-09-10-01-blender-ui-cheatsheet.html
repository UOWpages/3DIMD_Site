Blender UI CheatSheet

Quick reference for modeling in Blender (Default Keymap)

Windows

  • Go to top corner of a window to get a �+� sign
  • This can be dragged down to form a new window.
  • Dragging this across an existing window give the option to split it.
  • It can also be dragged into an existing window to join them.

Modes & Navigation

  • Tab: Toggle Object/Edit Mode
  • 1 / 2 / 3: Vertex / Edge / Face select (Edit Mode)
  • Middle Mouse Button (MMB): Orbit
  • Shift + MMB: Pan
  • Scroll Wheel: Zoom
  • Numpad 1 / 3 / 7: Front / Right / Top orthographic views
  • Ctrl + Numpad 1/3/7: Opposite view
  • Numpad 5: Toggle perspective / orthographic

Transform Basics

  • G: Grab / Move ? then X / Y / Z to constrain (e.g., G ? Z)
  • R: Rotate ? R ? X/Y/Z to constrain
  • S: Scale ? S ? X/Y/Z to constrain
  • Shift (hold): finer control when transforming
  • Ctrl + A (Object Mode): Apply ? Location / Rotation / Scale

Selection Tools

  • A: Select all / deselect all
  • B: Box Select (or LMB and drag)
  • C: Circle Select
  • L: Select linked (hover then L)
  • Alt + Click (edge): Select edge loop
  • Ctrl + Alt + Click (edge): Select edge ring (keymap dependent)
  • Ctrl + L: Select linked geometry under cursor

Modeling Operations (Edit Mode)

  • E: Extrude (faces/edges/verts)
  • I: Inset faces
  • F: Make face / fill
  • Ctrl + R: Loop Cut (click, then move; right-click to center)
  • Ctrl + B: Bevel (edges) � mouse wheel to add segments
  • X / Delete: Delete (choose Vertices / Edges / Faces / Only Faces / Edges & Faces)
  • M: Merge (or Move to collection in Object Mode)
  • P: Separate ? Selection (make new object)
  • K: Knife tool (click to cut; Enter to confirm)
  • V: Rip (separate verts) / (depends on keymap)
  • Alt + M (or M in some keymaps): Merge vertices by center / at cursor

Proportional Editing

  • O: Toggle Proportional Editing
  • Mouse wheel: change influence radius while transforming

Snapping

  • Shift + Tab: Toggle Snapping
  • Hold Ctrl while transforming: temporary snap
  • Snap types: Vertex / Edge / Face / Increment (set in header)

Modifiers (non-destructive workflow)

  • Mirror: Add Modifier ? Mirror (enable Clipping to weld center)
  • Subdivision Surface (Subsurf): Smooth geometry; use supporting loops to keep edges crisp
  • Boolean: Add Modifier ? Boolean (use carefully; clean topology after)
  • Bevel, Solidify, Array: common helpers
  • Order matters: modifiers apply top ? bottom in the stack

Shading & Viewport

  • Z: Quick shading pie (Wireframe, Solid, Material Preview, Rendered)
  • Right-click ? Shade Smooth / Shade Flat
  • Overlays (top-right in 3D View): toggle face orientation, normals, grid, origins
  • X-Ray / X-Ray slider: select through geometry
  • Show Gizmo, Show Overlays, Toggle Xray and ViewPort Shading is ideal for modeling

Outliner & Scene Management

  • Collections: Group objects for visibility / render
  • Select Filter for Restriction toggles (icons in Outliner for below)
  • Click icons in Outliner to toggle Visibility / Selectability / Render
  • Rename objects (double-click in Outliner) � keep names clear

Common Cleanup & Tools

  • Ctrl + J: Join selected objects
  • Alt + J: Convert tris?quads (if available)
  • Mesh ? Clean Up: Merge by Distance (remove doubles), Delete Loose, etc.
  • Ctrl + Shift + R / Ctrl + 2/3: Quick Subdivision shortcuts (Ctrl+2 = add Subsurf level + apply visually)

Quick Workflow (Box Modeling ? Refine ? Detail)

  1. Block out main forms using primitives (Cube, Cylinder, Sphere).
  2. Add Mirror modifier for symmetry.
  3. Use Loop Cuts (Ctrl+R) to add detail loops where needed.
  4. Bevel (Ctrl+B) or add supporting loops to control edge sharpness.
  5. Add Subdivision Surface and Shade Smooth for preview.
  6. Add fine details last; apply boolean only when necessary and retopologize afterwards.

Useful Shortcuts (compact)

  • Tab (Object/Edit), G (Translate), R (Rotate), S(Scale), E (Extrude), I(Insert), F, Ctrl+R (Loops), Ctrl+B (Bevel), Shift+D (Duplicate), X (Delete), P (Separate), Ctrl+A (Apply transforms), O (Proportional editing), Shift+Tab (snap)

Tips & Best Practices

  • Keep quads for clean deformation and subdivision.
  • Work non-destructively: use modifiers; apply only when necessary.
  • Apply transforms (Ctrl+A) before boolean/bevel to avoid issues.
  • Use supporting loops for sharp edges under Subsurf.
  • Organize into collections and name objects clearly.
  • Save incrementally (model_v01.blend, model_v02.blend).
