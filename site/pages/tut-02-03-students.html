Stretch Task: New Input System, Input Actions

Stretch Target: New Input System - Input Actions

This is an extension to Tutorial 02/03. Tutorial 00/01 introduced the New Input System using direct keyboard access. In this tutorial we introduce Input Actions.

Input Actions allow us to separate the physical input device from the gameplay action. Instead of asking the keyboard directly for W, A, S or D, the script can ask for a logical action such as Move.

We will use Input Actions to control the two Tutorial 02/03 character controllers:

Learning Concept Example: What you will learn
What you will learn
- What an Input Action is.
- How to create an Input Actions asset.
- How to create an Action Map.
- How to create Actions.
- How to create keyboard bindings.
- How to use a 2D Vector composite for WASD and Arrow Keys.
- How to use an InputActionReference in a script.
- How to read a Vector2 input value.
- How input can control Transform movement.
- How input can control Rigidbody physics.
- Why physics movement uses FixedUpdate().
- How the same Input System can support different controllers.

10. Complete WASD Physics Controller

WASD_addForce_PhysicsController_NIS.cs
using UnityEngine;
using UnityEngine.InputSystem;
 
public class WASD_addForce_PhysicsController_NIS : MonoBehaviour
{
[SerializeField] private InputActionReference moveAction;
[SerializeField] private float moveForce = 10f;
 
private Rigidbody rb;
 
void Awake()
{
rb = GetComponent<Rigidbody>();
}
 
void OnEnable()
{
moveAction.action.Enable();
}
 
void OnDisable()
{
moveAction.action.Disable();
}
 
void FixedUpdate()
{
Vector2 input = moveAction.action.ReadValue<Vector2>();
 
Vector3 force = new Vector3(
input.x,
0f,
input.y
);
 
rb.AddForce(force * moveForce);
}
}

11. Understand the Vector2 input

The WASD Action produces a Vector2.

Learning Concept Example: Vector2
W = Y +
S = Y -
A = X -
D = X +

We convert this 2D input into a 3D force:

Code Example
Vector3 force = new Vector3(input.x, 0f, input.y);

The X value controls world X. The Y value from the Vector2 becomes world Z. The 3D Y value remains zero.

13. Why use FixedUpdate()?

    1. The WASD controller uses Rigidbody.AddForce().
    2. Rigidbody physics should be handled in FixedUpdate().
    3. The input value is read inside FixedUpdate() and then used to apply the force.

15. Complete Arrow Transform Controller

Arrows_transformRotation_CharController_NIS.cs
using UnityEngine;
using UnityEngine.InputSystem;
 
public class Arrows_transformRotation_CharController_NIS : MonoBehaviour
{
[SerializeField] private InputActionReference moveAction;
[SerializeField] private float moveSpeed = 5f;
[SerializeField] private float rotationSpeed = 5f;
 
void OnEnable()
{
moveAction.action.Enable();
}
 
void OnDisable()
{
moveAction.action.Disable();
}
 
void Update()
{
Vector2 input = moveAction.action.ReadValue<Vector2>();
 
transform.Translate(
Vector3.forward * input.y * moveSpeed * Time.deltaTime,
Space.Self
);
 
transform.Rotate(
0f,
input.x * rotationSpeed * Time.deltaTime,
0f
);
}
}

19. InputActionReference

The controller scripts use an InputActionReference. This allows a script to reference one particular Action from the Input Actions asset.

22. Troubleshooting

    1. Move Action is empty in the Inspector
      1. Select the GameObject containing the controller script.
      2. Assign the correct Action to the Move Action field.
      3. For the physics controller use:
        4. WASD Action
        Player / Player_WASD_Physics_AddForce_Move
      4. For the Transform controller use:
        5. Arrow Action
        Player / Player_Arrows_Transform_Rotation_Move
    2. WASD does not move the physics object
      1. Check that the object has a Rigidbody.
      2. Check that the Rigidbody is not Kinematic.
      3. Check that the WASD Input Action is assigned.
      4. Check that the bindings are W, A, S and D.
    3. The Arrow character does not move
      1. Check that the Arrow Input Action is assigned.
      2. Check the four Arrow Key bindings.
      3. Check that Right is assigned to Right Arrow.
    4. The wrong character responds to the keys
      1. Check which Input Action is assigned to each controller's Move Action field.
      2. Each controller should reference its own Move Action.
23. What you should understand before continuing
An Input Actions asset contains input definitions.
An Action Map groups related Actions.
An Action represents a gameplay input such as Move, Look or Accelerate.
Bindings connect physical controls to Actions.
A 2D Vector Composite combines four directional controls into a Vector2.
InputActionReference allows a script to reference a specific Action.
ReadValue<Vector2>() reads the current value of a Vector2 Action.
Different scripts can use different Actions from the same Input Actions asset.
Transform movement can be performed in Update().
Rigidbody physics is performed in FixedUpdate().
The input system provides input; the controller script determines what the input does.
