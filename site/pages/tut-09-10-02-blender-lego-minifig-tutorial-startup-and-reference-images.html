Setup Reference Images in Blender:

This short tutorial shows how to add front and side reference images in Blender, position them, and group them into a separate collection so you don't select them by accident.

User Interface

User Interface:

  • Top Menu - Layout (for Now)
  • Scene Collection Menu
  • ViewPanes
  • XYZ gimbal,
    • Top menu -
      • Show Gizmo
      • Show Overlays
      • Toggle X Ray
      • Viewport Shading
      • Object/Edit Mode
      • Tab, 1,2,3
      • New windows -
        • Go to top right
        • Hover to get +
        • Drag down for new window or Window/New Window in top menu
  • SideBar
    • N to toggle open and closed, or arrow beside Scene Collection Menu to open
  • Item, Tool, View
  • Editor Type Panel
  • Typical Menus are Object, Modifiers at the moment
  • Navigation and Interaction
    • Shift MMB to drag/pan
    • MMB to rotate
    • Z + wheel to select wireframe or rendering options
    • Shift + A to add objects
  • Save frequently
    • Press Ctrl+S regularly to save your progress.
    • Have a number at the end of your file name to increment.
    • Press the "+" and save button to increment save.
    • New scene: File => New => General (or Ctrl+N)
    • Delete extras (optional - can use existing cube): select object => X => Enter
    • Work in Layout Workspace with 2 x Xray views and full coordinate reference while checking in Modeling for finished view
    • Drag another 3D View window out in Layout to be side by side
    • Select X axis Gimbal in Left window and Y axis Gimbal in right

Reference Images

    • In the 3D View (Object Mode, Layout Tab), =>
    • Drag a new window in from the top right corner.

Reference Image Side - Orthographic X view in Layout

    • Make this the right hand window - click X in Gimbal top right for Orthographic X
    • In Orthographic X axis View, =>
    • Press Shift-A to get Menu and Select: Add => Image => Reference.
    • In the file browser select your front/side reference image => Enter
    • The image will appear facing the front view.
    • MMB mouse drag out to perspective view
    • With reference object/image selected:
    • Press G => X => type in -5 => Enter (or mouse drag after G and X are pressed) to move reference out of center for modeling.
    • Press N to open Sidebar => Item => Transform if you want to type exact location values
    • Name this in Outliner Scene Window as Reference Side

(the jpg is the child of the object)

    • Click x gimbal to get out of perspective view
    • Press G => Y to drag the reference object so the Z axis is in line with the centre line of the side view of the head. (will be -0.75m Y)

Reference Image Front - Orthographic Y view in Layout

    • Do steps from adding Image Reference Side above in the Orthographic Y axis window but with G => Y
    • Name this in Outliner Scene Window as Reference Front
    • Use G => X to drag the reference object so the Z axis is in line with the centre line of the front view of the head.

Group reference images into a new collection

    • Select both reference images (select one, then Shift+click the other).
    • Press M => New Collection to move them into a new collection.
    • Name the collection "References" (or "Reference").

Prevent accidental selection of reference images

    • In the Outliner, disable selection for the Reference Images, =>
    • Click the selectable-toggle / arrow icon.
    • This way your cube/model is selectable and not your reference images.
    • If you can't see the selection-toggle icons in the Outliner, =>
    • Open the Outliner filter menu and enable the icons

(Filter => Show Restriction Toggles).

Make the cube transparent (so you can see the reference)

    • Press Z to toggle viewport shading so the cube becomes transparent/see-through
    • Use Wireframe/Solid and X-Ray/Viewport Shading in top viewport menu

Notes and tips:

  • Common shortcuts used:

      • G = Grab/Move

      R = Rotate, X/Y/Z to constrain transform axis

      Shift+D = Duplicate

      M = Move to collection.

      Z toggles a viewport shading pie on your Blender setup, =>

      choose Wireframe or X-Ray mode so the cube is easier to see.

  • Use the Outliner to manage visibility and selectability for a cleaner workflow.
  • These steps assume default Blender keymap and typical Outliner settings.
